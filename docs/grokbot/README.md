# Material para bots de conteúdo (Grok)

| Arquivo | Onde usar |
|---|---|
| `01-base-de-conhecimento-vista-ideia.md` | Anexar nos **dois** bots |
| `02-bot-roteirista.md` | Instruções do **Bot 1** — pautas, roteiros, legendas |
| `03-bot-diretor-de-arte.md` | Instruções do **Bot 2** — imagens e prompts de imagem |

Fluxo: Bot 1 gera o roteiro e termina com o bloco `PARA O DIRETOR DE ARTE` → cole no Bot 2 → Bot 2 gera as imagens.
Preencha os campos `{entre chaves}` da base (handle, link, produtos) antes de usar.

**Regras de ritmo humano (25/11/2026):** anexe também `regras/RITMO-HUMANO.md` nos dois bots. Legenda e dado parados pelo menos 1,5 s, uma ideia por vez com destaque no que está sendo mostrado, nada de texto miúdo pensando no celular. Vale para qualquer IA, não só Grok.
